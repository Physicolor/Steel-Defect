### 3. AI模型服务

#### YOLO模型加载
```python
async def _load_yolo_model(self):
    from ultralytics import YOLO
    self.yolo_model = YOLO(settings.YOLO_MODEL_PATH)
    if DEVICE != "cpu":
        self.yolo_model.to(DEVICE)
```

#### 图片检测
```python
async def detect_image(image_path, conf_threshold, iou_threshold):
    results = self.yolo_model(
        image_path,
        conf=conf_threshold,
        iou=iou_threshold,
        imgsz=settings.IMG_SIZE
    )
    
    events = []
    for result in results:
        for box in result.boxes:
            events.append({
                "class_name": result.names[int(box.cls)],
                "confidence": float(box.conf),
                "bbox": box.xyxy[0].tolist()
            })
    
    return events
```

## API接口实现

### 1. 认证接口

#### 用户注册
```
POST /api/auth/register
请求体：
{
    "username": "string",
    "password": "string",
    "email": "string",
    "phone": "string",
    "company_name": "string",
    "user_type": "personal|enterprise|admin"
}

响应：
{
    "id": "string",
    "username": "string",
    "user_type": "string",
    "created_at": "datetime"
}
```

#### 用户登录
```
POST /api/auth/login
请求体：
{
    "username": "string",
    "password": "string"
}

响应：
{
    "access_token": "string",
    "refresh_token": "string",
    "token_type": "bearer"
}
```

### 2. 检测接口

#### 图片检测
```
POST /api/detection/image
请求体：multipart/form-data
- file: 图片文件
- conf_threshold: 置信度阈值
- iou_threshold: IOU阈值

响应：
{
    "id": "string",
    "batch_id": "string",
    "defect_count": 0,
    "events": [
        {
            "class_name": "string",
            "confidence": 0.0,
            "bbox": [0, 0, 0, 0]
        }
    ]
}
```
