## 注意事项

### 1. 环境变量配置
需要创建 `.env` 文件配置以下变量：
```env
# 应用配置
DEBUG=True
HOST=0.0.0.0
PORT=8000

# 安全配置
SECRET_KEY=your-secret-key

# ChromaDB配置
CHROMADB_HOST=localhost
CHROMADB_PORT=8001

# AI模型配置
YOLO_MODEL_PATH=./models/best.pt
USE_CUDA=True

# 讯飞API配置
SPARK_API_KEY=your-api-key
SPARK_IMAGE_APP_ID=your-app-id
SPARK_IMAGE_API_KEY=your-api-key
SPARK_IMAGE_API_SECRET=your-api-secret
```

### 2. 模型文件
需要将YOLO模型文件（.pt）放到 `models/` 目录。

### 3. 数据目录
确保以下目录存在且有写入权限：
- `data/chromadb/`
- `uploads/`
- `captures/`
- `logs/`

### 4. 依赖安装
```bash
# 后端依赖
cd backend
pip install -r requirements.txt

# 前端依赖
cd frontend
npm install
```

### 5. 启动命令
```bash
# 开发环境
docker-compose -f docker/docker-compose.dev.yml up -d

# 生产环境
docker-compose -f docker/docker-compose.yml up -d
```
