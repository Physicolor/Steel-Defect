## 1. 系统概述与架构

### 1.1 系统功能

本系统是一个**面向工业质检的钢材缺陷轻量级检测系统**，核心功能包括：

- **YOLO26 目标检测**: 基于 YOLO26 的钢材缺陷实时检测，支持多种缺陷类型识别
- **UNet 语义分割**: 基于 Channel-UNet 的缺陷区域分割（备选方案）
- **图片检测**: 上传图片进行缺陷检测，生成标注图、热力图、裁剪图
- **摄像头实时检测**: 支持本地摄像头和IP摄像头的实时视频流检测
- **AI智能分析**: 集成讯飞星火大模型，对检测结果进行智能分析和建议
- **用户认证系统**: JWT 令牌认证，支持个人用户、企业用户、管理员三种角色
- **检测记录管理**: 检测结果持久化存储、分页查询、筛选、删除
- **管理员看板**: 用户管理、检测统计、数据趋势分析
